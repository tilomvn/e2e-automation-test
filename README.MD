# End To End Automation Test Using Jasmine(Mocha, Cucumber, Serenity)
* Jasmine: https://jasmine.github.io/
* Must have nodejs installed in mechine

* Setup
 - npm install
 - npm install -g protractor
 - npm install -g webdriver-manager
 - webdriver-manager update
 - webdriver-manager start
* Testing Report: ./e2e/report/index.html
* Testing Spec: Page Objects
* Testing Suites: update new suite into protractor.conf.js
